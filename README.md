# 💜 Rakami Tech — Linktree

Um agregador de links no estilo Linktree, desenvolvido especialmente para a **Rakami Tech**. O projeto foi construído focando em performance, design moderno e animações fluidas para conectar os clientes diretamente às redes sociais e canais de atendimento.


## 🚀 Tecnologias Utilizadas

* **React:** Biblioteca principal para a construção da interface.
* **Vite:** Ferramenta de build.
* **Tailwind CSS:** Framework utilitário para estilização rápida e responsiva.
* **React Bits:** Componentes e animações interativas para elevar a experiência visual.
